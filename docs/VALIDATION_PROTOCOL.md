# ORBVI 全包占据与局部通行验证协议

本工程目标是完整处理 `orbvi_4vl_data.bag` 中 `/orbvi/lidar/custom` 的 **2348 个扫描**。片段测试用于工程调试，不作为最终完成判据。最终判据以提取 manifest 中实际扫描数量、首末扫描时间和每帧结果为准。

## 输出含义与坐标

所有局部点、TT 占据中心和射线原点都必须位于同一当前重力对齐 LiDAR 坐标系，单位为米。`pose` 是该坐标系到固定世界系的 `T_world_from_current`。局部栅格数组轴序为 `[x,y,z]`，通行图为 `[x,y]`；PNG 横轴 x、纵轴 y。ROS bag 记录时间、传感器 header 时间不能混用，完整性验收使用与提取帧 manifest 相同的传感器扫描时间。

`occupied3d` 是 TT-Occ 输出，保留原始 Gaussian 膨胀结果。`observed_free` 由实际 LiDAR 射线补充，只标记射线经过的体素，近端回波优先，同角度更远回波不用于认证近端后方为空闲。射线末端保留至少一个体素的余量；未被射线穿过且未被 TT 占据的体素仍为未知。

相机深度比较路线也支持每点独立的相机原点 `ray_origins=N×3`。必须设置 `free_evidence_source="predicted_camera_depth"`：这些射线来自模型深度预测，不能宣称是真实传感器已经确认的自由空间。该路线把所有满足几何净空的 class 3 降为 class 2，并在元数据和图题中明确预测证据来源。每条路线应使用独立的 `LocalTraversability` 实例，避免混合证据来源。

`collision3d` 用于通行转换。Gaussian 的有限尺度会把真实地面沿高度方向膨胀，直接把全部 TT 地面占据视为障碍会阻塞车道。若提供 `fused_source_points`，在可信地面模型下仅移除距地面残差不超过容差的**真实回波来源**，然后对非地面来源重新执行同一 TT Gaussian 体素算子。真实低矮障碍即使与地面 Gaussian 重叠，仍贡献完整障碍 Gaussian。`occupied3d` 始终保留，不能用净空碰撞栅格替代报告 TT 算法占据输出。没有来源或没有可信地面时，采用原始占据，保守地保留阻塞。

输出四类通行状态：

| 数值 | 类别 | 判据 |
|---|---|---|
| 0 | unknown | 缺少可信地面或足够射线证据；也包括传感器未覆盖区域 |
| 1 | blocked | 设备高度区间内有碰撞占据，并按 footprint 膨胀 |
| 2 | partial_clearance | 有地面支持和部分净空射线，仍有未知体素；不作为已确认可通行区域 |
| 3 | observed_clearance | footprint 内每个需要检查的高度体素均有真实射线自由证据，且有地面支持、无碰撞占据 |

在局部地图边界，footprint 侵入地图外的格子不能确认为完整净空。`occupancy2d` 中“至少一个自由体素”的列投影仅用于观察传感器覆盖，不能当作三维净空证据。

## 地面、坡度和设备尺寸

地面估计先按 XY 小块选取较低回波，再做限制坡度的 RANSAC 平面与最小二乘拟合。只有足够回波数量、足够 XY 覆盖和允许坡度的平面才有效。支持区域由接近该平面的真实地面回波给出，有限距离扩展用于采样间隙；不能因为拟合出平面就假设整张图都是已观察地面。

当前实现适合局部近似平面车库地面；坡道接缝、多层台阶、强遮挡可能导致未知增多。失败时不强行假设水平地面。设备长度、宽度、安全余量和高度全部可配置，默认 `0.7 × 0.55 m` footprint、`0.1 m` 余量和 `1.0 m` 高度只是演示设备假设，不能作为真实车辆尺寸。通行 footprint 使用矩形外接圆，因此对未知航向保守。

0.3 m 体素和约 0.08 m 地面容差意味着低于容差/分辨率的矮障碍不可保证辨认；稀疏 Livox 射线会令很多看似空旷区域保持部分净空或未知。更密集通行候选与已验证自由区域必须分开统计。

自由证据只保留有限帧数和时间窗，旧自由体素先转换到世界系，再以当前 pose 转回局部系。没有 pose 时只使用当前扫描。历史不包含未来帧，过期帧会被移除；动态物体和配准误差仍可能破坏短时地图一致性，工程不能替代实际车辆安全验证。

## 几何比较与评价边界

最终生产主线使用每帧完整有效 LiDAR 回波构建 TT 占据、时间融合和局部通行，覆盖全部 2348 帧。

比较至少包含单帧 TT Gaussian 占据和因果多帧 TT Gaussian 占据，记录占据体素数、历史新增体素、帧延迟、地面有效性、各通行类别面积。单帧/多帧射线观察地图可以作为观察覆盖基线，它们不能代替 TT 占据输出。

独立回波评价采用额外的影子预测分支：在预先规定的每 50 帧评价位置，将单帧点云按整个 0.3 m 空间体素划分为约 90% 构建回波和 10% withheld 回波。相同源体素和重复点不能同时进入构建与评价集合。影子占据、射线和地面估计不得使用 withheld 回波。主线输出保持全点构建，影子结果单独标记，不能把主线全点输出与这些 withheld 点的对应关系当作独立验证结果。

单帧影子占据使用当前局部点，无需配准 pose 即可做 heldout endpoint 检查。多帧影子评价若使用全扫描得到的 LiDAR 配准 pose，存在位姿条件依赖；它只是**给定估计位姿条件下的几何一致性评价**，不称为严格独立端到端真值。当前帧空间 withheld 区域若曾被历史完整扫描观测，同样应注明这是时序覆盖比较。无需语义标签的几何函数也可以用于相机输出，但米制尺度和参考系必须独立确认。

报告以下指标：

- withheld endpoint hit rate：局部评价点落入预测占据的配置体素邻域的比例。邻域采用显式 Chebyshev 体素容差，不能误写为精确欧氏距离。
- false-free rate：withheld 实际回波所在体素被构建分支射线认证为空闲的比例。未观测/地图外点不称为自由。
- 按回波数加权的汇总值，以及评价帧数、有效 withheld 回波数、无评价点帧数。无回波评价时指标为 unavailable/null，不能报告完美分数。

这些点云是观测一致性证据，不是完整三维真值；不报告自建数据的语义 mIoU、隐藏区域占据准确率或真实可安全驾驶概率。同一份输入雷达与自己的占据高匹配只说明重建保真度。

## 全包验收

`FullBagAcceptance` 检查帧 ID 必须恰好为 `0..2347`，无缺失、无重复、无失败、无乱序，扫描时间必须严格递增。若提供 manifest 首末时间，结果时间必须精确对应，不能以短片段碰巧达到某个输出数量替代全包覆盖。输出同时列出空输入/空占据帧和生成通行输出的帧数，便于人工审核。完整运行应保存每帧结果或足以恢复逐帧结果的索引和源数据；可视化采用配置步长，不影响数值处理覆盖。

工程合成测试涵盖未知保持未知、近回波后的射线遮挡、坡度地面、墙体 footprint 膨胀、地面 Gaussian 来源去除而低障碍保留、运动补偿与历史过期、未知高度层不能提升为完整净空、重复点/源 ID 的 holdout 防泄漏，以及全部 2348 帧与时间边界的验收。

图像从真实输出生成，采用相同米制范围、最近邻显示和显式未知颜色；不平滑、不补齐未观测区。PNG 配套 JSON 记录类别、轴序、源 NPZ 和变换。全局展示若点数过多仅作均匀行号采样，记录显示数量，不修改保存的真实数值。

## 独立文件验收命令

在项目目录执行：

```bash
.venv/bin/python scripts/verify_run.py --run runs/lidar_full
```

脚本逐个读取全部扫描来源、占据、通行和启用时的像素语义 NPZ，并比较源 manifest、逐帧 JSON、最终汇总、代码/标定/模型来源指纹。它要求原始点总数为 **46,929,024**，所有 2348 帧都有连续索引及相同首末时间，无效零回波单独计数，不作为障碍构建输入。自由与碰撞占据必须互斥；未经确认 LiDAR—相机标定时，LiDAR 语义必须保持 unknown=255。地面拟合无效时，`ground_plane` 中 NaN 是显式缺失状态，不能当作有效平面；其他几何坐标、覆盖比例和 pose 必须有限。

脚本独立检查所需全部文件及汇总一致性，不仅信任 `summary.complete`。成功退出码为 0，未完成、文件异常、被图像元数据覆写的汇总或仅处理片段时退出码为 2；默认写 `verification.json` 和中文 `verification.md`。相机路线使用 `--run runs/camera_full`，要求同样全部 2348 个 10 Hz 时步，并明确完整保留 20 Hz 原始图像不等于逐幅进行推理。

位姿若采用 `trajectory_report.json` 的 VIO roll/pitch 约束，验收报告会披露：米制 ICP 不使用 VIO 平移或尺度，但旋转稳定性不是纯 LiDAR 信息。单帧空间 holdout 不使用该配准位姿。若通行认证格为零，报告直接说明没有认证通行区域，不通过降低未知判据制造通行结果。
